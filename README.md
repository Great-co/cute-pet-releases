## Cara memasang

1. Klik link **⬇️ DOWNLOAD CUTE PET** di atas. File `Cute-Pet-Setup.exe` akan terunduh.
2. Kalau browser bilang file ini *jarang diunduh*, klik **⋯** (atau tanda panah) lalu pilih **Keep / Simpan**.
3. Buka file `Cute-Pet-Setup.exe` dari folder **Downloads**.
4. Kalau muncul layar biru **"Windows protected your PC"**:
   - klik tulisan **More info**,
   - lalu klik tombol **Run anyway**.

   Ini muncul karena Cute Pet masih aplikasi baru dan belum punya sertifikat berbayar dari Microsoft, bukan karena berbahaya.
5. Tunggu sebentar. Cute Pet terpasang otomatis dan bebeknya langsung muncul di layar 🎉

## Cara bermain

- **Klik kanan bebek** atau klik **tab kuning kecil di tepi kanan layar** untuk membuka panel.
- **Tarik makanan** dari tab *Makan* ke layar untuk memberi makan.
- **Tarik bebek** pakai mouse untuk memindahkannya.
- Ikon bebek di **pojok kanan bawah (dekat jam)**: klik kanan untuk menyembunyikan bebek, mematikan suara, atau keluar.

## Update

Cute Pet **memperbarui dirinya sendiri**. Kalau ada versi baru, bebek akan bilang *"Ada versi baru! 🎁"*.
Klik **Mulai ulang** di panel, atau biarkan saja dan update terpasang saat aplikasi ditutup.

## Cara menghapus

**Settings → Apps → Installed apps → Cute Pet → Uninstall.**
